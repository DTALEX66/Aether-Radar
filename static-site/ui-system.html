UI 生成系统 · 专属界面规范

把项目内容生成统一、可编程、可商用的专属 UI。

本页用于给 Codex、Claude Code、Cursor、Lovart、Figma AI、v0 等工具提供统一视觉依据：雷达、星图、信任评分、风险分层、数据卡片、全链路选型。

设计原则

不要做普通导航站；必须体现热度、风险、来源可信度、场景方案和多格式导出。

雷达感

用网格、扫描线、信号点表达发现与筛选。

可信感

用风险等级、来源可信度、核验时间支撑判断。

全链路

从发现、理解、筛选、对比到导出接入。

UI 系统是后续编程和 AI 生成界面的统一依据。
