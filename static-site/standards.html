v0.8 规范中心

把产品、品牌、UI、工程、数据、安全和发布规范统一到一套标准里。

本页用于让 Codex、Cursor、Claude Code、Cline、Figma AI、Lovart 和后续开发者快速理解继续开发 Aether Radar 必须遵守的规范。

规范地图

产品 → 品牌 → UI → 内容 → 工程 → 数据 → 安全 → 发布 → 未来规划。

产品执行规范

定位、用户、模块边界、产品判断公式。

品牌执行规范

品牌含义、语气、视觉方向、禁止项。

UI 设计规范

页面蓝图、组件、视觉层级、AI UI 生成方式。

工程执行规范

编码、数据同步、API、MCP、测试和 CI。

数据治理规范

字段、分类、去重、热度、风险和更新频率。

安全法律规范

风险、免责声明、隐私、商用判断。
