# 32 未来产品规划与扩展地图

## 1. 总目标

Aether Radar 最终要成为全链路 AI 生态导航、索引、筛选、风险提示、导出接入和持续更新平台。

最终不是一个静态网站，而是：

`AI 生态数据中心 + 工具选型系统 + 风险雷达 + 多格式导出 + API/MCP 数据服务 + 企业内部工具库`

## 2. 阶段规划

### Phase 0：基础资料包

- Excel/Markdown 原始资料。
- 种子数据。
- Codex Starter。
- 静态站。

### Phase 1：可运行 MVP

- Next.js 网站。
- 搜索筛选。
- 工具详情。
- GitHub 热榜。
- 风险中心。
- 场景方案。
- JSON/CSV/Markdown 导出。

### Phase 2：数据更新与导出增强

- GitHub API 自动更新。
- Excel/XLSX 导出。
- PDF 报告。
- Notion/飞书模板。
- 数据状态和更新日志。

### Phase 3：选型助手

- 自然语言搜索。
- 场景工具栈生成。
- A/B 对比推荐。
- 国内外替代品。
- 本地部署路线。
- 商用风险提醒。

### Phase 4：平台接入

- API。
- MCP Server。
- 浏览器插件。
- Raycast/Alfred 插件。
- VS Code 插件。
- 企业内部工具白名单。

### Phase 5：商业化与企业版

- 用户登录。
- 收藏和个人工具栈。
- 团队空间。
- 周报。
- 付费专业包。
- 企业风控白名单。
- 私有部署。

## 3. 关键扩展能力

| 能力 | 说明 |
|---|---|
| 趋势榜 | 7 日/30 日增长，抓新兴工具。 |
| 风险评分 | 隐私、版权、商用、许可证、安全、维护、国内可用性。 |
| 可信来源 | 官网/GitHub/论文/平台公开/人工审核。 |
| 多端导出 | Excel、CSV、JSON、Markdown、Notion、飞书、PDF。 |
| API/MCP | 让 AI Agent 和企业系统直接查工具库。 |
| 个人工具栈 | 用户保存自己的 AI 工作流。 |
| 企业白名单 | 企业管理允许和禁止使用的 AI 工具。 |
| 浏览器插件 | 用户在网页看到工具名时一键查看风险。 |

## 6. 护城河路线

1. 不是收录最多，而是结构化最好。
2. 不是推荐最猛，而是风险最清楚。
3. 不是单端导出，而是多端可迁移。
4. 不是静态导航，而是可接入 API/MCP。
5. 不是普通中文站，而是适合中文用户项目落地和商业判断。

## 7. 长期愿景

> 成为中文用户选择、理解、评估、组合、导出和接入 AI 工具的第一入口。
