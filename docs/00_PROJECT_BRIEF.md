# 00 项目简报

## 项目名

AI 生态雷达 / AI Ecosystem Radar

## 最终目标

打造一个 **全链路 AI 集合导航、索引、筛选、导出、接入、持续更新的平台**。

它覆盖：

- AI 模型
- AI 工具
- AI 平台
- GitHub 开源项目
- Agent / MCP / A2A / AG-UI / NLWeb
- Vibe Coding / AI 编程
- 设计 / 图像 / 视频 / 音频
- 知识库 / RAG / 第二大脑
- 自动化 / Workflow
- 本地部署 / 省钱方案
- 浏览器 Agent / Web 自动化
- 办公 / 内容 / 数据分析
- 安全 / 风险 / 合规
- 多格式导出与系统接入

## 核心定位

不是告诉用户“哪个工具最好”，而是把工具能力、热度、风险、成本、适用场景、替代方案、接入方式透明化，让用户自己做出更安全、更适合自己的选择。

## 产品关键词

全链路、工具雷达、开源热榜、风险评级、场景方案、多格式导出、平台中立、持续更新。
