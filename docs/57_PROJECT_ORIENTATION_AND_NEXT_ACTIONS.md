Date: 2026-06-29

## One-line Product Definition

Aether Radar is a platform-neutral AI ecosystem radar for discovering, evaluating, comparing, exporting, and integrating AI tools, models, agents, workflows, risks, scenarios, and source evidence.

It is not a plain AI tool directory, not a Codex-only helper, and not an Obsidian-only knowledge base.

## Data and Content Rules

1. `data/seeds/*.json` is the canonical data source.
2. `next-app/data/` is a mirrored runtime copy generated by `npm run sync:data`.
3. Every entity should preserve source URL, risk level, license/commercial note, China usability, maintenance/review signal, and last verified date.
4. Full collection and curated recommendation must stay separate.
5. Stars and collection count are popularity signals, not quality guarantees.
6. New ingestion or learning-route features must preserve source quality, risk visibility, and user choice.

## Current Known Limitations

- `next-app/node_modules` is not currently installed in this local checkout, so TypeScript/lint/build were not rerun during consolidation.
- Some older Chinese documents appear visually garbled in PowerShell output. Encoding preflight passes, but content cleanup may still be useful as a later editorial pass.
- The XLSX export is a generated static workbook suitable for current self-check and basic handoff. A richer styled workbook generator can be added later.
- The MCP server is a local read-only prototype, not a production integration layer.
- Production SaaS features such as auth, billing, online editing, audit logs, monitoring, and data update pipelines are documented but not complete product systems.
