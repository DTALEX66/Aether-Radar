# 计费、API Key 与使用限制规范

## 计费层级建议

| 层级 | 能力 |
|---|---|
| Free | 搜索、基础筛选、部分导出。 |
| Pro | 完整 Excel/PDF、趋势榜、高级筛选、个人工具栈。 |
| Team | 团队工具库、白名单、成员权限、协作审核。 |
| Enterprise | 私有部署、API/MCP、高级审计、企业风险策略。 |

## API Key 类型

- read_only：读取实体、风险、场景、导出。
- reporting：生成报告。
- admin_review：创建审核任务。
- enterprise_sync：同步企业内部工具库。

## 限制策略

| 能力 | Free | Pro | Team | Enterprise |
|---|---:|---:|---:|---:|
| 搜索请求/天 | 100 | 5,000 | 50,000 | 自定义 |
| Excel 导出/月 | 3 | 100 | 1,000 | 自定义 |
| PDF 报告/月 | 1 | 50 | 500 | 自定义 |
| API 请求/月 | 0 | 10,000 | 100,000 | 自定义 |

## 风险控制

1. API Key 不允许明文展示完整值。
2. 高风险导出需要二次确认。
3. 企业版可配置禁用外部跳转。
4. 使用量必须进入 audit_logs。
