# 42｜v1.0 Changelog

## 新增

- `/stack` 我的 AI 工具栈。
- `/report` 选型报告生成器。
- `/admin` 数据审核与运营看板。
- `/deploy` 部署与商用展示页面。
- `/api/report` 场景报告 API。
- `/api/openapi` API 规范接口。
- `/openapi.json` 静态 OpenAPI 文件。
- Dockerfile、docker-compose.yml、vercel.json。
- GitHub Actions build workflow。
- 部署 Runbook、商用展示验收清单、企业/SaaS 架构规划、报告与工具栈规范。

## 增强

- 工具卡片和详情页可加入本地工具栈。
- API 文档加入报告和 OpenAPI 端点。
- 自检脚本新增 v1.0 商用展示能力检查。
- 静态站新增工具栈、报告、审核、部署预览页。

## 边界

v1.0 是商用展示版，不是完整生产 SaaS。生产版仍需账号、权限、数据库、在线编辑后台、支付、日志、监控和正式法律文案。
