# UI 页面蓝图

## 首页

目标：5 秒内说明 Aether Radar 是全链路 AI 工具选型平台。

模块：雷达 Hero、全局搜索、数据健康条、核心入口、精选高热工具、场景方案、高风险关注、分类覆盖、免责声明。

## 工具库

目标：快速筛选工具、平台、开源项目和协议。

模块：搜索、分类、热度、风险、来源可信度、开源、本地部署、API、MCP、全量/精选切换、工具卡片。

## 工具详情页

目标：让用户在进入官网前先判断适不适合自己。

模块：工具说明、关键标签、热度、来源、风险仪表、商用判断、许可证、价格、国内可用性、适合场景、来源链接。

## 风险中心

目标：把风险提示变成产品差异化。

模块：七大风险、核验流程、高风险工具示例、用户自行选择声明。

## 场景方案库

目标：根据“我要做什么”推荐工具组合。

模块：适合人群、工具组合、难度、成本、本地部署、商业化、风险、替代方案。

## 导出接入中心

目标：平台中立，数据不锁死。

模块：JSON、CSV、Markdown、Excel、Notion、飞书、PDF、API、MCP、浏览器插件、周报。

## UI 系统和 UI 生成器

目标：让后续编程和设计都围绕同一套界面语言。

模块：视觉定位、颜色令牌、组件注册表、页面蓝图、生成提示词、负面约束。
