# 37｜商用成品缺口报告

## 当前已经接近商用 MVP 的部分

- 产品定位清晰。
- UI 系统与品牌规范完整。
- 数据模型、风险模型、导出模型已成型。
- 静态页面和 Next.js 页面结构完整。
- 有 Excel、JSON、CSV、Markdown 导出。
- 有 API 路由和 MCP 本地只读原型。
- 有编码、语法、数据、规范、UI、API/MCP 自检。

## 仍不是完整商用 SaaS 的原因

1. 尚未在联网 Node 环境完成 `npm install && npm run build`。
2. 数据仍是种子库快照，不是持续更新数据库。
3. GitHub 指标更新脚本尚未接入定时任务。
4. 平台价格、隐私政策、商用条款仍需要人工复核流程。
5. 没有登录、收藏、团队空间、权限、审计日志。
6. API 尚无认证、限流和数据版本签名。
7. MCP Server 仍是本地只读原型。
8. 没有支付系统、付费下载和企业版管理后台。

## 到可商用版本的最短路线

### v1.0 商用展示版

- 完成 Next.js build。
- 部署到 Vercel / Cloudflare Pages。
- 数据保持 JSON 静态快照。
- 提供免费搜索、基础导出、风险提示。
- 提供付费版 Excel/报告下载的人工交付流程。

### v1.1 数据更新版

- GitHub API 定时更新。
- 数据审核状态流转。
- 更新日志页面。
- 7日/30日趋势榜。

### v1.2 用户版

- 登录。
- 收藏工具。
- 我的工具栈。
- 导出记录。
- 周报订阅。

### v1.3 企业版

- 团队空间。
- 白名单/黑名单。
- 私有化部署。
- API Key。
- MCP Server 权限控制。
- 审计日志。
