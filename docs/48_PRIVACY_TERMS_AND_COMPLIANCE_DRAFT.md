# 隐私政策、服务条款与合规草案

> 本文是产品草案，不构成法律意见。正式商用前必须由专业法律人员复核。

## 隐私政策要点

1. 说明收集哪些数据：账号、邮箱、收藏、工具栈、导出记录、API 使用记录。
2. 说明不应上传敏感信息：商业机密、个人身份信息、医疗/金融敏感资料。
3. 说明第三方工具跳转风险。
4. 说明数据保存和删除方式。
5. 说明企业版私有部署边界。

## 服务条款要点

1. Aether Radar 是信息索引与选型参考平台，不保证第三方工具能力、价格、可用性或安全性。
2. 用户应自行核验官网、许可证、隐私政策、价格和商用条款。
3. 平台不对第三方工具造成的损失承担直接责任。
4. 禁止滥用 API、爬取、重售未授权数据。
5. 平台可对高风险或过期工具进行下架或标记。
