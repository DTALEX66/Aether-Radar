# 25 品牌执行规范

## 1. 品牌名

主品牌：Aether Radar  
中文名：AI 生态雷达

## 2. 品牌含义

- Aether：代表 AI 生态中不可见但连接一切的信息层、工具层和协议层。
- Radar：代表发现、扫描、评估、追踪和预警。
- AI 生态雷达：代表中文用户可理解的全链路 AI 工具选型平台。

## 3. 品牌定位

> 帮用户从海量 AI 工具、平台、模型、Agent 和开源项目中，看清能力、热度、风险、替代品和适用场景，并用自己的方式导出和接入。

## 4. 品牌关键词

| 关键词 | 表达方式 |
|---|---|
| 可信 | 来源、风险、更新时间、核验状态 |
| 专业 | 数据结构、评分模型、对比、场景方案 |
| 中立 | 不绑定 Codex、不绑定 Obsidian、不替用户做唯一选择 |
| 全链路 | 发现、理解、筛选、对比、风险、导出、接入、更新 |
| 可迁移 | Excel、CSV、JSON、Markdown、Notion、飞书、PDF、API、MCP |
| 雷达感 | 扫描、星图、信号、热区、风险层级 |

## 5. 品牌语气

### 应该

- 清楚、克制、专业、可验证。
- 用“建议”“适合”“谨慎”“需核验”表达判断。
- 明确区分事实、推测、人工判断和平台口径。
- 把风险讲清楚，让用户自己选择。

### 不应该

- 不说“全网最全”“绝对安全”“一定可商用”。
- 不把 GitHub Stars 等同于质量。
- 不说“这个工具最好”，应说“更适合某类场景”。
- 不做夸张营销文案，不做焦虑式引导。

## 6. 品牌视觉方向

| 元素 | 标准 |
|---|---|
| Logo | 雷达光点 + Aether 星轨，可抽象，不要复杂写实。 |
| 主色 | 深空蓝、信任蓝、青绿色信号色、橙色风险提示。 |
| 背景 | 轻网格、扫描线、淡星图，不喧宾夺主。 |
| 卡片 | 数据密度高但留白足，必须展示标签和评分。 |
| 图标 | 线性、科技、简洁，避免可爱风和泛 AI 机器人。 |
| 动效 | 扫描、浮动、渐进显示；不要夸张旋转和游戏化过强。 |

## 7. 标语库

- 发现 AI 工具，看清热度与风险。
- 不只收录工具，更帮你判断适不适合。
- 从工具导航，到全链路 AI 选型。
- 数量不等于质量，选择前先看风险。
- 用你自己的方式导出、接入和沉淀 AI 工具库。

## 8. 品牌禁止项

- 禁止把界面做成普通网址导航 Logo 墙。
- 禁止只突出 Codex、Obsidian 或某个单一平台。
- 禁止大面积使用“AI 机器人头像”作为主视觉。
- 禁止无来源地展示“最强、第一、最安全”。
- 禁止把未审核工具显示为推荐工具。

## 9. 品牌一致性检查

每次新页面上线前检查：

1. 页面是否体现全链路？
2. 是否有风险提示？
3. 是否保留中立语气？
4. 是否使用统一 Logo、色彩、组件和标签？
5. 是否避免普通导航站风格？
