# 05 风险与信任模型

## 风险维度

1. 隐私风险
2. 版权风险
3. 商用风险
4. 许可证风险
5. 安全风险
6. 维护风险
7. 国内可用性风险
8. 成本风险
9. 平台锁定风险
10. 数据上传风险

## 风险等级

- 低：一般使用风险可控
- 中：需要核验条款/权限/数据流
- 高：涉及版权、账号权限、浏览器操作、代码执行、敏感数据等
- 未知：资料不足，不建议作为生产决策依据

## 信任评分建议

```text
推荐指数 = 热度分 + 维护分 + 来源可信度 + 可用性分 - 风险扣分
```

MVP阶段不强行计算分数，只显示：

- 热度等级
- 风险等级
- 维护状态
- 数据来源
- 最后核验日期
