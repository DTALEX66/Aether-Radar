# 01 产品需求文档 PRD

## 1. 背景

AI工具、模型、Agent、开源项目和平台快速增长，普通用户很难判断：

- 这个工具是什么？
- 有多热？
- 是否开源？
- 能不能本地部署？
- 是否适合商用？
- 有没有版权/隐私/安全风险？
- 国内是否可用？
- 有没有替代品？
- 我要做某个项目应该选什么组合？

## 2. 目标

MVP 目标：用一个静态数据驱动的网站，完成“搜索 + 筛选 + 风险提示 + 场景方案 + 导出”的闭环。

## 3. 用户故事

### 普通用户

我想知道某个AI工具是什么，并看到它的风险和替代品。

### 设计师

我想找到适合海报、文化墙、品牌视觉、视频生成的AI工具组合。

### 开发者

我想找高热开源项目，看Stars/Forks/License/是否维护。

### 项目经理

我想导出Excel或PDF报告，用于团队讨论和工具选型。

### 企业用户

我想知道哪些工具能私有化、哪些不能输入敏感数据。

## 4. MVP功能

- 首页
- 工具库
- 词汇百科
- GitHub热榜
- 风险中心
- 场景方案库
- 对比页
- 导出中心

## 5. 非目标

MVP 不做完整社区、不做复杂付费、不做自动AI推荐、不做全量爬虫。
