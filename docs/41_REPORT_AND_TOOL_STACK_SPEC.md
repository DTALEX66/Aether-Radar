# 41｜选型报告与个人工具栈规范

## 目标

把“查工具”升级为“形成项目决策”。v1.0 提供本地工具栈和选型报告原型。

## 我的工具栈

路径：`/stack`

能力：

- 搜索工具并加入浏览器本地工具栈。
- 记录项目名称、目标、负责人、预算和数据敏感度。
- 汇总工具数量、分类覆盖、开源、本地部署和高风险数量。
- 导出 JSON。
- 导出 Markdown。
- 打印或另存 PDF。

边界：

- 数据存于浏览器 localStorage，不上传云端。
- 不构成采购建议或法律建议。
- 正式版需要账号、团队、权限和审计。

## 选型报告

路径：`/report`

能力：

- 选择场景方案。
- 自动匹配推荐工具组合。
- 展示难度、成本、本地部署可能性和推荐路径。
- 导出 Markdown。
- 打印或另存 PDF。

生产版扩展：

- 品牌封面。
- 客户名称。
- 数据版本。
- 来源清单。
- 风险签收。
- 审核人。
- PDF 模板。
- 团队评论和审批。
