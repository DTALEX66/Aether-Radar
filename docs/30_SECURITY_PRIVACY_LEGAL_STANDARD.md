# 30 安全、隐私与法律执行规范

## 1. 总原则

Aether Radar 是信息索引与选型参考平台，不替用户做法律、安全、采购、投资或商用授权判断。

必须做到：

- 风险透明。
- 来源可查。
- 判断克制。
- 用户自主选择。
- 免责声明可见。

## 2. 风险维度

| 风险 | 说明 |
|---|---|
| 隐私风险 | 用户数据是否上传云端，是否适合企业敏感资料。 |
| 版权风险 | 生成内容、模型、素材、LoRA、训练数据可能涉及版权。 |
| 商用风险 | 免费版/模型/素材是否允许商业使用。 |
| 许可证风险 | MIT、Apache、GPL、AGPL、闭源、未知许可证差异。 |
| 安全风险 | 插件、MCP、浏览器 Agent、代码 Agent 可能越权。 |
| 维护风险 | 项目归档、停更、依赖过旧、Issue 堆积。 |
| 国内可用性风险 | 登录、支付、访问、API、中文支持不稳定。 |

## 3. 高风险类别

必须重点提示：

- AI 绘图/视频平台：版权、肖像、模型授权、NSFW。
- 模型社区：模型来源、训练数据、商用许可证。
- Browser Agent：误点击、账号权限、网页提示注入。
- MCP Server：工具投毒、权限过大、数据泄露。
- Coding Agent：误删文件、泄露 API Key、生成危险代码。
- 自动化工作流：重复发送、误删数据、越权调用。
- 企业知识库：隐私、数据驻留、合规。

## 4. 页面必须出现的声明

工具详情页、风险中心、导出中心、对比页必须保留类似声明：

> 本页面仅用于信息索引与选型参考，不构成法律、安全、财务、采购或商用授权建议。AI 工具的价格、能力、隐私政策、许可证和商用条款可能变化，使用前请核验官网、许可证、隐私政策和服务条款。

## 5. 数据隐私规范

MVP 阶段不默认收集用户敏感数据。

后续若加入登录、收藏、工具栈、企业版，必须明确：

- 收集哪些数据。
- 为什么收集。
- 保存多久。
- 是否给第三方。
- 是否支持删除。
- 是否支持导出。

## 6. API/MCP 安全规范

后续 API/MCP 必须：

- 只读优先。
- 默认不返回敏感用户数据。
- 输出包含风险提示。
- 对写操作使用审批机制。
- 有速率限制。
- 有审计日志。
- 不把“推荐”伪装成“安全保证”。

## 7. 开源许可证提示

| 许可证 | 风险提示 |
|---|---|
| MIT / Apache-2.0 | 通常较宽松，但仍需核验。 |
| GPL | 分发衍生作品可能触发开源义务。 |
| AGPL | 网络服务使用也可能触发开源义务，商用谨慎。 |
| 商业闭源 | 以服务条款为准。 |
| 未知 | 默认标为需核验。 |

## 8. 商用判断文案

只能使用：

- 可商用
- 需核验
- 谨慎使用
- 不建议
- 未知

禁止使用：

- 绝对可商用
- 无版权风险
- 官方保证安全
- 可放心商用

## 9. 发布前安全检查

- 风险中心是否可访问？
- 工具详情是否有风险说明？
- 导出内容是否包含免责声明？
- 高风险类别是否特别提示？
- 是否把收录误写成推荐？
- 是否有“绝对安全/绝对可商用”等禁用词？
