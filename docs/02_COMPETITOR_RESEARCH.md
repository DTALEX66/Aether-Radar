## 产品结论

不要和竞品比“谁收录最多”。可以做“收录数量榜”，但必须提示：数量不等于质量。

我们的核心差异：

1. 全量收录 + 精选推荐双模式
2. 风险与商用提示
3. GitHub热度 + 维护状态 + License
4. 国内外替代与国内可用性
5. 场景方案库
6. Excel / Markdown / Notion / 飞书 / JSON / API / MCP 多出口
