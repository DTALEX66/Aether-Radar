# 08 缺失与优化报告

## 当前已补足

- 不再局限 Codex
- 不再局限 Obsidian
- 加入多格式导出：Excel、CSV、JSON、Markdown、Notion、飞书、PDF、API、MCP
- 加入竞品/灵感分析
- 加入安全风险和用户自主选择提示
- 加入全量收录与精选推荐双模式
- 加入场景方案库
- 加入开源热度和维护状态概念
- 加入国内可用性和国内替代品方向

## 仍需后续强化

1. 数据自动更新：GitHub API、平台信息定期核验。
2. 工具详情页：补充更多真实来源和截图。
3. 许可证解析：自动识别MIT/Apache/GPL/AGPL/未知。
4. 价格字段：免费/Freemium/订阅/按量/企业版。
5. 用户收藏：个人工具栈和团队工具栈。
6. AI推荐：先规则化，后续再加模型推荐。
7. 质量评分：热度不等于质量，需要综合维护、License、风险。
8. 社区提交：需要审核机制，避免垃圾工具和钓鱼链接。
9. 内容合规：图像/视频/音频工具必须提示版权和肖像风险。
10. 企业版：私有部署、权限、审计、白名单/黑名单。
