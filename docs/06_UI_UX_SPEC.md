# 06 UI / UX 规范

## UI目标

参考 Toolify、Futurepedia、Future Tools、Glama、Product Hunt、Hugging Face 的信息密度和卡片结构，但做出自己的差异：风险标签、场景方案、导出接入、国内可用性。

## 视觉方向

- 深色/浅色均可，MVP采用浅色高级科技风。
- 主色：深蓝 / 靛蓝 / 青蓝。
- 辅色：绿色表示开源/本地，橙色表示中风险，红色表示高风险。
- 卡片式布局，顶部大搜索框。
- 左侧/顶部筛选栏。
- 首页要有“不是只收录，而是帮你选型”的文案。

## 页面布局

### 首页

- 顶部导航
- Hero 区：标题 + 副标题 + 搜索框 + CTA
- 指标卡片：收录工具、分类、开源项目、风险维度、导出格式
- 热门分类 Grid
- 精选工具卡片
- 风险提示条
- 场景方案入口

### 工具卡片

必须包含：

- 名称
- 直译/中文名
- 类型
- 类别
- 一句话解释
- 热度等级
- 风险等级
- 开源/本地部署标签
- 国内可用性
- 官网/详情按钮

### 风险中心

用矩阵展示：风险维度 × 工具类型。

### 导出中心

把 Excel、CSV、JSON、Markdown 作为可用按钮；Notion、飞书、PDF、API、MCP 作为规划中卡片。
