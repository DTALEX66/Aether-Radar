# 39｜v1.0 商用展示版验收清单

## 定位验收

- 不是普通 AI 工具导航。
- 不绑定 Codex。
- 不绑定 Obsidian。
- 支持全量收录与精选推荐。
- 支持风险提示，让用户自己选择。

## 页面验收

- 首页能说明项目价值。
- 工具库能搜索和筛选。
- 工具详情能显示热度、风险、来源、商用、价格、许可证、国内可用性。
- 风险中心能解释隐私、版权、商用、许可证、安全、维护、国内可用性。
- 场景方案能给出工具组合。
- 导出中心能下载 JSON、CSV、Markdown、XLSX。
- API 文档能打开接口。
- UI 系统和规范中心能指导后续开发。
- 工具栈、报告、审核、部署页面可演示。

## 数据验收

- 实体 ID 不重复。
- GitHub 仓库不重复且格式为 owner/repo。
- 分类引用有效。
- 高风险实体必须有清晰风险说明。
- 商用字段不为空。
- 来源可信度不为空。

## 商用展示边界

v1.0 可以用于演示、内部评估、交给 Coding Agent 继续开发、包装为资料包。它不是完整生产 SaaS。

生产 SaaS 必须继续补：账号、权限、在线编辑、数据库、支付、API Key、监控、审计、隐私政策、服务条款和真实数据复核。
