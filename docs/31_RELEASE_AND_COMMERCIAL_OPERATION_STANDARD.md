# 31 发布与商业化运营规范

## 1. 发布目标

先做可信 MVP，再做付费包，再做 SaaS/企业版。

不能在数据和风险体系不成熟时过早宣传为“商用级安全选型平台”。

## 2. 版本路线

| 阶段 | 目标 | 标准 |
|---|---|---|
| v0.8 | 规范完整 | 产品、品牌、UI、内容、工程、数据、安全、发布规范齐全并可自检。 |
| v0.9 | 技术可运行 | Next build 通过，API、Excel 导出、MCP 草案、本地查询可用。 |
| v1.0 | 公开演示 | 可部署，可搜索筛选，可导出，风险和免责声明完整。 |
| v1.2 | 数据更新 | GitHub 指标自动更新，新工具候选池，更新日志。 |
| v1.5 | 个人工具栈 | 收藏、对比、个人方案、周报、Notion/飞书/PDF。 |
| v2.0 | 平台服务 | API/MCP、企业白名单、团队空间、付费订阅。 |

## 3. MVP 发布清单

- 首页表达清楚。
- 工具库能搜索筛选。
- 工具详情可访问。
- 风险中心可访问。
- 导出中心可下载 JSON/CSV/Markdown。
- 数据状态页显示数量和更新时间。
- 免责声明可见。
- sitemap/robots 存在。
- 编码/数据/自检脚本通过。
- Next build 通过。

## 4. 商业化顺序

### 第一阶段：资料包

- 完整 Excel 数据库。
- Markdown/Obsidian/Logseq 包。
- Notion/飞书模板。
- PDF 选型报告。

### 第二阶段：专业包

- AI 设计工具包。
- AI 编程工具包。
- AI 本地部署工具包。
- AI 自动化工作流包。
- AI 企业知识库工具包。
- AI 风险避坑包。

### 第三阶段：SaaS

- 高级筛选。
- 趋势榜。
- 工具对比。
- 收藏和个人工具栈。
- 周报订阅。
- API/MCP 订阅。

### 第四阶段：企业版

- 企业内部 AI 工具白名单。
- 风险审批。
- 团队工具栈。
- 私有部署。
- 审计日志。
- 自定义分类。

## 5. 内容运营节奏

| 内容 | 频率 |
|---|---|
| 每周 AI 工具新增榜 | 周更。 |
| GitHub 7 日增长榜 | 周更。 |
| 高风险工具观察 | 双周。 |
| 场景方案更新 | 月更。 |
| 数据库大版本 | 月更。 |
| 商用风险专题 | 月更。 |

## 6. 收费边界

免费：基础搜索、基础词条、部分风险、部分榜单。  
付费：完整数据库、高级筛选、导出、趋势榜、场景方案、PDF 报告、周报。  
企业：内部白名单、私有部署、API/MCP、权限、审计。

## 7. 发布风险

- 数据过期：必须显示 `lastVerifiedAt`。
- 商用误解：必须有免责声明。
- 数量竞争：必须强调数量不等于质量。
- 过度承诺：避免“最全、最安全、最强”。
- 维护成本：必须自动采集 + 人工精选。

## 8. 上线后指标

| 指标 | 说明 |
|---|---|
| 搜索次数 | 用户是否真的查工具。 |
| 筛选次数 | 筛选体系是否有价值。 |
| 详情页点击率 | 卡片信息是否吸引。 |
| 导出次数 | 资料包/付费潜力。 |
| 对比页使用率 | 选型价值。 |
| 风险中心访问 | 风险差异化是否成立。 |
| 周报订阅 | 持续更新价值。 |
| 付费下载率 | 商业验证。 |
